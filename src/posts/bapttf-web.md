Mon site personnel et portfolio. Construit avec SvelteKit (frontend) et un backend Go,
déployé en GitOps via ArgoCD sur mon cluster Kubernetes.

Le site héberge mon blog technique, mes projets, et un terminal interactif (Hall of Root).

Stack : SvelteKit, TypeScript, Go, Docker, ArgoCD, Kubernetes, GitHub Actions
